## 2026-07-21 Addendum — corrected live vs. killed vaccine claim; new reference [6] added

Following the same fix already applied to Course 15 (Serology 101), the user flagged this course's own version of the same error: the Introduction's "Vaccination Versus Immunity: A Short Primer" section said a killed vaccine "by itself... gives a weaker immune 'signal,'" which contradicted the course's own later claim (Section 5) that "Inactivated vaccines are the cornerstone of antibody-based protection programs in laying and breeding flocks [21→22]," and contradicted the corrected Course 15 immunology (live = cell-mediated/Type 1 dominant, killed = antibody/humoral/Type 2 dominant, per Merck Veterinary Manual).

- **Live file identified first.** Confirmed `Course 8/RV-revised-NB-edited course 8 draft.docx` (not the stale `Course 8/Revised Course 8.docx`, and not the non-existent `Vaccination_draft.docx` the old README pointed to) is the actual published file by matching its byte size exactly against `dashboard/public/docs/course-08-vaccination-treatment.docx`.

Available from: merckvetmanual.com/pharmacology/vaccines-and-immunotherapy/types-of-vaccines-for-animals — same source verified for the Course 15 fix (author Ian Rodney Tizard, reviewer Joyce Carnevale, last updated April 2026; confirms live vaccines trigger a Type 1/cytotoxic-T-cell-dominant response, killed vaccines trigger a Type 2/antibody-dominant response and typically need an adjuvant/multiple doses).
- **Content fix:** rewrote the killed-vaccine paragraph in the primer to say it "leans on the antibody arm of immunity rather than the cell-mediated arm," ties into the "two arms" framing already established earlier in the same Introduction (cited to [2]), and removed the flat "weaker" framing.
